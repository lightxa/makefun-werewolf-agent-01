A deterministic scripted Werewolf player in pure Python, standard library only, with no model calls: it tracks claims, votes and night results, exposes liars, and plays all four roles, hiding as a wolf and leading as the seer.

## Run it

```sh
MAKEFUN_ENV_URL=<env origin> python3 main.py
```
